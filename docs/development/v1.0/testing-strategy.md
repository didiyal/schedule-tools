# 测试策略 — v1.0

本项目目前以**人工验证**为主，暂无自动化测试套件。以下为关键路径与易错点清单，供回归验证使用。

## 测试方式

- 手动运行 `cd workspace && python main.py`（开发）或双击 `待办计时器.exe`（打包）。
- 按 [验收标准](../../product/v1.0/acceptance-criteria.md) 逐项核对。

## 关键回归路径

1. 计时：开始 / 暂停 / 重置 / 移除；运行中退出 → 重启补算接续。
2. 计时提醒：达到目标时长弹窗 + 声音 + 通知，不重复；重置后再触发。
3. 顶部吸附：吸顶收起 → 进入展开 → 离开收回，且不影响主窗口滚轮。
4. 三态筛选与跨日完成归当天。
5. 拖拽排序仅同组生效、落点指示线、5px 阈值区分点击。
6. 系统托盘最小化 / 双击恢复 / 退出；开机自启注册表增删与勾选态刷新。
7. 数据：原子保存、`.bak` 回退、旧数组格式兼容、归档。

## 易错点（来自开发记录，重点验证）

- `int(time.time())` 截断亚秒差为 0：测试计时相关逻辑需 sleep ≥ 1.2s。
- 无边框窗口可置屏幕负坐标，吸附依赖此特性，勿假定坐标恒为正。
- TimerRow 时间 Label 需先于文本 pack（RIGHT 优先），否则时间被挤出。
- Canvas 内嵌 Frame 的 `<Configure>` 需手动更新 `scrollregion`。
- Observer 回调用列表存引用，TimerPanel 必须用 `remove_callback()` 精确移除自己的那条，否则内存泄漏。
- 滚轮用 `bind_all` 绑定到窗口级并做顶层窗口坐标守卫，避免停在子控件上失效或串扰计时面板。
