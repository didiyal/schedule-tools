
# 更新日志

## v1.4.3 — 2026-10-28（仅安卓 APP + 服务端版本号）

### 修复/改进（安卓 APP）

- **任务树支持收起/展开**：有子任务的主任务显示折叠箭头（收起状态本地记忆）；
- **含子任务的主任务不再显示计时按钮**（时长=子任务之和，与桌面规则一致，
  卡片时间显示子树汇总）；
- **右侧三个按钮收进「⋯」操作面板**：底部弹出 开始/暂停计时、添加子任务、
  删除——手机屏不适合横排多按钮（用户拍板）；
- **修通知栏「暂停」无效**：通知 id 改为按任务 id 确定性派生——此前多任务
  槽位制下后台暂停清不掉对应通知，暂停成功但通知继续走字，看起来没停；
  App 重启后残留通知自动清理。

> 每个版本的详细变更见对应 `product/<版本>/changelog.md`。

## v1.4.1 — 2026-10-28

### 修复

- **手机新建的任务电脑端无法操作（加入计时面板/右键全部静默失效，重启才恢复）**：
  云同步合并后只重建了视图、没重建 `_byId` 索引——远端新增条目不在索引里，
  面板/勾选/删除/开始/暂停全部静默 return。现在合并回调统一走
  `AbsorbRemoteChanges()`（重建索引 + 刷新 id/order 高水位，后者同时修掉
  两端「最大数字 id+1」造号在合并后撞号的隐患）。
- **跨日结转保留重点标识**：有进度旧树结转时，今天新建的承接根现在继承
  旧根的 ★（此前新建根默认无重点；无进度整棵顺延本就保留）。
- **改任务名/星标计时面板不更新**：面板刷新守卫只比对 id 序列，改名不改 id
  被同值守卫吞掉——改为内容签名（id/文本/星/完成/运行）比对，改名后面板立即刷新。
- **更新提示误报**：此前「服务器版本 ≠ 本地」就提示更新，本地超前时也误报；
  改为语义化版本比较、仅服务器更新时提示。
- **安卓 release 包缺 INTERNET 权限**：debug 清单自动带 INTERNET，release 不带
  且主清单从未显式声明——release 包连不上服务器（「连接失败」）。已显式声明。

### 新增（安卓 APP）

- **计时常驻通知**：有任务在计时时，通知栏常驻显示「任务名 + 系统原生秒表」
  （chronometer 自动走字，无需轮询），点通知回 APP，「暂停」按钮停表并同步
  服务器；进程被杀后点暂停由后台 isolate 直接写本地文件并尽力直推。
  Android 13+ 首次启动请求通知授权。
- **APP 自更新机制**：服务端新增 `GET /api/app/latest` 下发最新 APK（免鉴权，
  走同一钉扎证书），healthz `app` 字段即最新版本号；APP 连接时比对本地版本，
  有新版在界面顶部出「有新版本 X.X.X，点此更新」横幅——下载（进度条）完成后
  拉起系统安装器，从此手机端不用再手动传包。发布流程见
  `server/TodoSync/README.md`「APP 更新包发布」。

## v1.5 — 2026-10-27（首个公开安装包发布）

### 新增

- **每日顺延**：跨日自动结转——旧日没完成的任务搬到今天；有进度的旧树
  留「已结转」快照（灰字角标+降透明，不占 Completed 语义、不污染统计/归档）；
  无进度的树整棵顺延不留残根；未完成叶挂到今天的新根下（同名承接、
  同名不合并）；已完成子树下的未完成孙任务也顺延（深度回落仍 ≤3 层）。
  触发：启动时 + 常驻过午夜（幂等：已结转根不再处理）。
  变更为普通条目修改，走既有 LWW 同步，服务端/手机端零改动。
- **补卡语义**（2026-10-27）：完成不再强制改期到今天——归入任务当前所属日期。
  昨天忘勾的任务今天补勾，完成状态留在昨天的历史组（GUI 与 CLI done 一致；
  顺延已搬到今天的任务勾选后留在今天，日期由顺延/拖拽/新建决定）。
- **顺延语义修订**（2026-10-27 用户验收两轮后）：①未完成叶不看日期——旧树
  只要有未完成后代（含已跨日的），今日一律建新根收编，不再出现"今天看不到
  结转树"；②今日承接根完成后，沿 rolled_from 链把旧日结转根同步置完成
  （历史快照跟随翻篇；GUI 与 CLI done 一致；取消完成不逆翻）。
- **云同步三端**：TodoSync 服务端 + 桌面同步模块 + 安卓 Flutter APP（见各 README）。
- **每日顺延**：跨日自动结转（详见 v1.5 各项）。
- **服务端空间隔离（多用户）**：todos/devices 增加 space_id，令牌绑定空间、
  API 全量按空间过滤（互相不可见）；配对码可指定空间；存量数据自动归入
  default 空间（服务端启动自动迁移）。共享清单（一空间多用户）留待后续。
- **安装包与更新机制（M5）**：`TodoTimer_Setup_1.4.0.exe`（Inno Setup，self-contained
  零依赖，按用户装 LocalAppData\Programs，免管理员）；固定 AppId 与 1.2 一致 →
  原地升级自动继承 data/；旧 Python EXE 安装时清理；运行中实例自动关闭。
  更新检查：服务端 healthz/changes 下发 app 版本号，桌面端不一致时状态栏提示
  "有新版本"。一键打包：`installer/build_installer.bat`（publish → ISCC）。

## v1.2.0 — 2026-10-23

### 新增

- **任务树**：任务可挂子任务（最多 3 层：主任务 → 子任务 → 子子任务）。
  右键「➕ 添加子任务」；Tab / Shift+Tab 降级 / 提升层级；拖拽三区落点——
  目标卡片上/下 25% = 同父兄弟插入（蓝色指示线）、中间 50% = 成为子任务
  （绿色边框 + 缩进绿线），成环与超层自动拦截弹回，拖父任务整枝跟随。
  父卡片显示子进度 `n/m` 与折叠箭头 ▸/▾（折叠状态持久化，快速连点不误触
  计时面板）。删除 = 连同子任务整枝删除（Ctrl+Z 可整枝恢复）；「清除已完成」
  归档时未完成后代自动上抛最近的未归档祖先。
- **分页加载**：列表每页最多渲染 30 张卡片，尾部「加载更多（还有 N 项）」
  按钮 + 滚动到底自动追加（防抖）；一次新增卡片超过 10 张自动分帧补齐，
  不冻结 UI。切日期 / 切筛选 / 改搜索时页容量重置。
- **CLI 树支持**：`list` 输出新增 `parent` / `depth` 字段，排序改为 DFS
  森林序（与界面显示一致，父必在子前）；`list --tree` 树形缩进显示；
  `add "文本" --parent 父id` 直接建子任务；`reparent <id> (--parent 父id |
  --top)` 移动整枝（目标不存在 / 成环 / 超 3 层拒绝）；`delete` 语义改为
  连同子任务整枝删除（回显删除条数）。

### 调整

- **视图筛选改造**：去掉 未完成/已完成/全部 三段切换按钮，默认显示全部；
  改为「筛选」栏两个勾选项（未完成 / 已完成，可叠加；双勾或都不勾 = 全部）。
- **每日一棵树**：全部视图按日期倒序分组，每组内是当天任务的树——子任务
  永远挂在父任务下（与父不同日期时显示日期角标），完成与未完成在同一棵树
  内直观可见。排序与完成态解耦（重点 → 顺序），完成/取消不移动任何卡片。
- **完成态视觉**：完成的任务卡片变绿（绿底 + 绿色 accent + `[已完成]`）、
  文字变灰（时间加删除线）；筛选勾选时未命中节点被剔除、命中者的祖先链
  保留并灰显撑住结构。

### 修复

- CLI start 语义对齐 GUI：启动时把任务加入计时面板（此前不加面板，启动了
  也看不见）；已完成 / 已在运行的任务如实报错 / 提示，不再误报 running。
- 重新打包 EXE：包含 CLI 服务与 `待办计时器.exe cli` 入口（此前的 EXE 构建
  早于 CLI 功能，CLI 只能降级直写文件且会被运行中的旧版覆盖——即「cli 启动
  任务看不到变化」的根因）。
- 修复 CLI 多 id 批量在「GUI 未运行且未显式 `--headless`」时整条失败的问题
  （现在自动降级逐条处理，成功项仍持久化）。
- 修复快速连点折叠箭头会误触「双击加入计时面板」的问题（Tk 对 500ms 内的
  第二次 press 只派发 Double-Button-1，箭头已接管该事件）。

### 已知问题

- 拖拽「成为子任务」（目标卡片中间 50% 区域）实测不生效；兄弟插入、
  Tab 降级、右键添加子任务不受影响。下版修复。

## v1.4.0 — 2026-10-26（随 v1.5 发布线首次公开发布）

### 重写与新增

- **技术栈迁移**：C#/.NET 8 + WPF 全量重写（渲染性能），workspace/ Python 1.2 线删除，
  版本号 1.2.0 → 1.4.0（跳过 1.3），标题「待办计时器 1.4」。
- **任务树**：3 层、折叠、子进度 n/m、删整枝+Ctrl+Z 恢复、归档未完成后代上抛；
  父任务卡三档视觉与叶子区分——一级蓝底+粗蓝框+明显投影、二级浅底+细框+弱投影、
  叶子纯白无框（父卡框线/投影不因完成消失，完成的底色仍变绿）；首次建子任务时
  父任务时长/面板身份自动迁移给同名子任务（父归零，满足"含子任务不可计时"规则）。
- **拖拽**：手动循环（弃 OLE），三意图横轴——最左提升带（拖成主任务）/内容左缘
  同级/偏右子级，影子跟随显示意图词，跨日期拖放=改期，今日空槽拖入=改到今天。
- **计时面板**：无边框置顶，▶/⏸/✓/✕ 行内操作，时间绑定刷新，重点 ★，
  含子任务任务不可入面板（时长=子任务递归汇总）。
- **筛选**：未完成/已完成/只看今日 + 搜索，今日栏常驻（空时给橙色拖放槽）。
- **美学统一**：新增设计令牌字典 `Themes/TodoTimer.xaml`（飞书浅色体系集中管理）；
  主窗口/计时面板/输入对话框/右键菜单/滚动条/复选框/按钮全面换肤（圆角、hover
  反馈、主次按钮层级）；图标弃 emoji 改用系统 Segoe Fluent Icons（含 ▶⏸✓✕ 星标、
  菜单图标）；子进度改浅灰胶囊；完成态文字删除线灰字；父任务卡三档视觉
  （一级粗蓝框+明显投影、二级细框+弱投影，框线完成态保留）。修复单实例激活
  因窗口标题缺「1.4」后缀而永远找不到窗口的 bug。
- **云同步 S2（对接 v1.5 服务端）**：`TodoItem` 契约新增 `updated_at`（旧数据
  兼容缺省 0）；新增 `Services/SyncService` + `Models/SyncOps`（指纹 diff、
  updatedAt 秒级 LWW、墓碑删除、失败重试）与 `syncstate.json` 状态文件；
  存盘自动推、30s 心跳拉取合并（含 CLI/外部改动对账）；状态栏显示同步状态，
  点击打开设置（服务器地址+管理员令牌，首次连接锁定自签证书指纹）。
  未配置时零联网，本地功能不受影响。
- **CLI/IPC**：`TodoTimer.exe cli` 13 命令 headless + GUI 在线写盘后 IPC 通知刷新；
  管道/文件重定向已支持；GUI 在线写不拒（与 1.2 相反）。
- **托盘/自启/单实例**、40+1 项 xunit。
