# 更新日志

> 每个版本的详细变更见对应 `product/<版本>/changelog.md`。

## v1.1.1 — 2026-09-12

### 修复

- **三态视图切换卡顿**：从未完成切到已完成/全部视图会冻结 7~15 秒。现改为
  渲染计划比对 + 卡片同值守卫 + scrollregion 合并刷新 + 原地增删 + 首屏即现/
  剩余分帧补齐 + 启动空闲预热，切换首次绘制降到约 50ms。
- **已完成视图取消完成无反应**：视图刷新会清空卡片选中状态，切视图后直接
  点 ✓ / Ctrl+Z 时静默无操作。现改为选中状态跟随目标卡片跨视图保留。
- 卡片内部标签与分组标题/空提示改用纯 tk 控件（外观不变），重排成本大幅下降。

详细变更见 [product/v1.1.1/changelog.md](product/v1.1.1/changelog.md)。

## v1.1 — 2026-07-01

### 新增

- UI 现代化：迁移 customtkinter，飞书风格圆角卡片视觉系统（配色 + `RADIUS` token）。
- Inno Setup 安装器：单用户、可选安装路径、固定 AppId 覆盖升级、卸载可选删本地数据、简中向导、应用图标。
- 顶部版本号显示（`v1.1.0`）。

### 优化

- 计时悬浮窗按钮重设计：实心彩色（▶绿 ⏸橙 ↺灰 ✕红 + 白图标），高对比可见。
- 三态切换预加载复用卡片，不再重建控件。
- 顶栏紧凑、卡片间分界、窗口/卡片尺寸与字号统一调整。

### 技术

- 依赖 +customtkinter；DPI 单一缩放源；版本号单源 `APP_VERSION`（与 `installer.iss` / 安装包名同源）。
- 详细变更见 [product/v1.1/changelog.md](product/v1.1/changelog.md)。

## v1.0 — 2026-06-25

### 新增

- 待办计时器 v1.0 首个正式版本：主窗口待办管理 + 统一计时悬浮面板。
- 顶部吸附、计时提醒、拖拽排序与落点指示线。
- 系统托盘最小化与开机自启、双击恢复。
- 数据安全（原子保存 / `.bak` 回退 / 运行恢复 / 归档）。

### 技术

- 三层分离架构 + Observer 回调 + 双 Tick。
- PyInstaller 单 EXE 打包（约 12 MB）。
