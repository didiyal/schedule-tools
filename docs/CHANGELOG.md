# 更新日志

> 每个版本的详细变更见对应 `product/<版本>/changelog.md`。

## v1.2.0 — 2026-10-23

### 新增

- **任务树**：任务可挂子任务（最多 3 层：主任务 → 子任务 → 子子任务）。
  右键「➕ 添加子任务」；Tab / Shift+Tab 降级 / 提升层级；拖拽三区落点——
  目标卡片上/下 25% = 同父兄弟插入（蓝色指示线）、中间 50% = 成为子任务
  （绿色边框 + 缩进绿线），成环与超层自动拦截弹回，拖父任务整枝跟随。
  父卡片显示子进度 `n/m` 与折叠箭头 ▸/▾（折叠状态持久化，快速连点不误触
  计时面板）。删除 = 连同子任务整枝删除（Ctrl+Z 可整枝恢复）；「清除已完成」
  归档时未完成后代自动上抛最近的未归档祖先。
- **分页加载**：列表每页最多渲染 30 张卡片，尾部「加载更多（还有 N 项）」
  按钮 + 滚动到底自动追加（防抖）；一次新增卡片超过 10 张自动分帧补齐，
  不冻结 UI。切日期 / 切筛选 / 改搜索时页容量重置。
- **CLI 树支持**：`list` 输出新增 `parent` / `depth` 字段，排序改为 DFS
  森林序（与界面显示一致，父必在子前）；`list --tree` 树形缩进显示；
  `add "文本" --parent 父id` 直接建子任务；`reparent <id> (--parent 父id |
  --top)` 移动整枝（目标不存在 / 成环 / 超 3 层拒绝）；`delete` 语义改为
  连同子任务整枝删除（回显删除条数）。

### 调整

- **视图筛选改造**：去掉 未完成/已完成/全部 三段切换按钮，默认显示全部；
  改为「筛选」栏两个勾选项（未完成 / 已完成，可叠加；双勾或都不勾 = 全部）。
- **每日一棵树**：全部视图按日期倒序分组，每组内是当天任务的树——子任务
  永远挂在父任务下（与父不同日期时显示日期角标），完成与未完成在同一棵树
  内直观可见。排序与完成态解耦（重点 → 顺序），完成/取消不移动任何卡片。
- **完成态视觉**：完成的任务卡片变绿（绿底 + 绿色 accent + `[已完成]`）、
  文字变灰（时间加删除线）；筛选勾选时未命中节点被剔除、命中者的祖先链
  保留并灰显撑住结构。

### 修复

- CLI start 语义对齐 GUI：启动时把任务加入计时面板（此前不加面板，启动了
  也看不见）；已完成 / 已在运行的任务如实报错 / 提示，不再误报 running。
- 重新打包 EXE：包含 CLI 服务与 `待办计时器.exe cli` 入口（此前的 EXE 构建
  早于 CLI 功能，CLI 只能降级直写文件且会被运行中的旧版覆盖——即「cli 启动
  任务看不到变化」的根因）。
- 修复 CLI 多 id 批量在「GUI 未运行且未显式 `--headless`」时整条失败的问题
  （现在自动降级逐条处理，成功项仍持久化）。
- 修复快速连点折叠箭头会误触「双击加入计时面板」的问题（Tk 对 500ms 内的
  第二次 press 只派发 Double-Button-1，箭头已接管该事件）。

### 已知问题

- 拖拽「成为子任务」（目标卡片中间 50% 区域）实测不生效；兄弟插入、
  Tab 降级、右键添加子任务不受影响。下版修复。

详细变更见 [product/v1.2/changelog.md](product/v1.2/changelog.md)。

## v1.1.1 — 2026-09-12

### 修复

- **三态视图切换卡顿**：从未完成切到已完成/全部视图会冻结 7~15 秒。现改为
  渲染计划比对 + 卡片同值守卫 + scrollregion 合并刷新 + 原地增删 + 首屏即现/
  剩余分帧补齐 + 启动空闲预热，切换首次绘制降到约 50ms。
- **已完成视图取消完成无反应**：视图刷新会清空卡片选中状态，切视图后直接
  点 ✓ / Ctrl+Z 时静默无操作。现改为选中状态跟随目标卡片跨视图保留。
- 卡片内部标签与分组标题/空提示改用纯 tk 控件（外观不变），重排成本大幅下降。

详细变更见 [product/v1.1.1/changelog.md](product/v1.1.1/changelog.md)。

## v1.1 — 2026-07-01

### 新增

- UI 现代化：迁移 customtkinter，飞书风格圆角卡片视觉系统（配色 + `RADIUS` token）。
- Inno Setup 安装器：单用户、可选安装路径、固定 AppId 覆盖升级、卸载可选删本地数据、简中向导、应用图标。
- 顶部版本号显示（`v1.1.0`）。

### 优化

- 计时悬浮窗按钮重设计：实心彩色（▶绿 ⏸橙 ↺灰 ✕红 + 白图标），高对比可见。
- 三态切换预加载复用卡片，不再重建控件。
- 顶栏紧凑、卡片间分界、窗口/卡片尺寸与字号统一调整。

### 技术

- 依赖 +customtkinter；DPI 单一缩放源；版本号单源 `APP_VERSION`（与 `installer.iss` / 安装包名同源）。
- 详细变更见 [product/v1.1/changelog.md](product/v1.1/changelog.md)。

## v1.0 — 2026-06-25
