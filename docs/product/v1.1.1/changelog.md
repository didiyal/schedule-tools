# 版本变更记录 — v1.1.1

v1.1.1 是修复版本：解决 **三态视图切换极度卡顿** 与 **已完成视图取消完成无反应**
两个问题。无新功能，无数据格式变更。

## 修复一：视图切换卡顿（未完成 ↔ 已完成 / 全部）

### 现象与量级（98 条待办、92 条已完成的实际数据）

| 操作 | 修复前 | 修复后 |
|------|--------|--------|
| 未完成 → 已完成（冷） | 15.1s 冻结 | 首屏 ~40ms，后台 1~2s 补齐 |
| 未完成 → 已完成（热） | 7.1s 冻结 | 首屏 ~25ms，后台 1.2s 补齐 |
| 已完成视图一次「取消完成」点击 | ~12s 冻结 | 34ms |
| ★ / 改文本 / 新增 / 删除 | 0.3~1s+ | 1~60ms |

### 根因（按贡献排序）

1. **Canvas scrollregion 联动放大**：卡片容器 `card_frame` 是 Canvas 的窗口
   item，其 `<Configure>` 直接 `canvas.configure(scrollregion=bbox("all"))`。
   每张卡片增删都触发一次 → Canvas 整体重绘。实测同样 98 张卡片，有无该
   联动差异为 312ms vs 2154ms（约 7 倍）。
   → 改为 50ms 合并刷新（主窗口与计时面板同改）。
2. **CTk 控件同值 configure 也重绘**：`_refresh_view` 对全部缓存卡片无条件
   `set_selected/set_dragging/refresh`（每次十余次 configure），而 CTk 的
   configure 即使值相同也走整控件重绘。
   → 所有 `configure` 加同值守卫；`TodoCard.refresh`/`TimerRow.refresh` 增加
   数据版本守卫（`TodoWidget._version`，`_fire_change` 时递增；`starred`/
   `visible` 等直接赋值字段一并纳入守卫键）。
3. **一次状态变更叠加 2~3 次全量刷新**：observer 双订阅（MainApp 直接订阅 +
   TimerPanel 回调再分发）+ 操作后显式调用。
   → `_refresh_view` 改为「先纯计算渲染计划，与上次一致则整体跳过」。
4. **卡片首次映射昂贵**（canvas 初始化 + 尺寸协商，远贵于重映射）。
   → 启动空闲期 `_prewarm_cards`：逐张 place 到可视区外完成首次映射再卸下，
   一次性成本摊到启动后台。
5. **卡片内部全是 CTk 控件**（外壳 + 4 容器 + 9 标签 = 14 个 CTk 控件，映射
   原生开销与 CTk 控件数量成正比）。
   → 内部标签/容器全部换纯 tk 控件（文字渲染无差异），仅外壳保留 CTk 圆角；
   底色由 `TodoCard._apply_fg` 统一同步（默认/选中蓝/悬停灰）。

### 渲染管线（新）

```
_refresh_view
  ├─ _compute_plan()        纯计算渲染计划（entries + 统计文本 + 数据指纹）
  ├─ 计划与上次相同          → 整体跳过（吸收 observer 双订阅/显式调用的重复刷新）
  └─ _materialize(entries)
       ├─ 卡片序列不变(改文字/★/完成态) → 同值守卫逐卡同步内容，零重排
       ├─ 纯增/纯删(完成/取消/搜索/新增/删除) → 只增删目标卡片（pack before/after
       │   锚点重挂轻量装饰），未变化卡片原地不动
       └─ 其余(切视图/排序) → 全量重排：首屏 14 条同步渲染，剩余按 80ms 预算
           分帧补齐（流式渲染令牌 `_render_seq` 使新计划即时作废旧流）
```

## 修复二：已完成视图取消完成无反应

### 现象

在已完成视图直接点 ✓ 工具栏按钮（或 Ctrl+Z）取消刚完成的待办，界面无任何
反应；切回未完成也看不到该任务。右键菜单「↩ 取消完成」不受影响。

### 根因

`_refresh_view` 每次执行都把 `_selected_tid` 清空。完成操作 → 刷新（选中
清空）→ 切到已完成视图 → 再刷新（仍无选中）→ 此时点 ✓ 走
`_get_selected_id()` 为 None 的静默分支，不刷新、不提示。

### 修复

- 选中状态跨刷新保留：刷新后若目标卡片仍在当前视图渲染中（含高亮），选中
  保持；只有目标任务不在当前视图时才清空。上述操作路径变成：切到已完成 →
  该卡片保持选中且高亮 → 点 ✓ 正确取消完成 → 切回未完成可见。
- 数据侧不变；未选中时 ✓/★ 等仍为无操作（有高亮即为选中，状态可见）。

## 其他

- 分组标题 `SectionHeader` / 空提示 `EmptyHint` 改纯 tk 控件（底色恒为列表
  底色，外观不变），配合装饰缓存跨刷新复用。
- 数据格式（`data/todos.json`）无变化；v1.1.1 可覆盖安装升级。
