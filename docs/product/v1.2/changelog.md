# v1.2.0 变更记录 — 任务树 · 分页加载 · 筛选改造 · CLI 树支持

发布日期：2026-10-23
设计稿：[design.md](design.md)（含用户拍板记录）

## 任务树

- 数据模型：每条任务新增 `parent` 字段（`null`=顶层主任务），兄弟顺序沿用
  全局 `order`。**纯增量字段**——旧版本程序读新文件忽略该键，新版本读旧文件
  默认顶层，双向无损兼容。
- 层级上限 3 层（主任务 → 子任务 → 子子任务）。所有入枝操作（拖拽/Tab/CLI）
  统一经 `src/tree.py` 的 `can_adopt` 校验：目标存在、非自身后代（成环）、
  深度不超限。
- 装载自愈 `tree.normalize`：外部手改 JSON 产生的悬空引用 / 环 / 超深枝，
  在装载时拍平为顶层，不崩溃、不渲染死循环。
- 交互入口：
  - 右键菜单「➕ 添加子任务」（对话框输入，日期继承父任务，父自动展开）；
  - 选中卡片 `Tab` 降为上一兄弟的最后子任务、`Shift+Tab` 提升为父的兄弟
    （右键菜单同款）；
  - 拖拽三区落点：目标卡片上 25% / 下 25% = 插到其上/下（同父兄弟序，蓝色
    指示线与卡片同缩进）；中间 50% = 成为其子任务（目标绿框 + 缩进绿线）。
    顶层兄弟插入维持同日期规则；无效落点无指示、松手弹回。
  - 拖拽虚影显示整枝规模（「含 N 个子任务」）。
- 折叠：父卡片序号前 ▸/▾ 箭头，点击只折叠/展开不选中；折叠状态持久化到
  `todos.json` 顶层 `collapsed` 数组。快速连点箭头不会误触「双击加入计时
  面板」（Double-Button-1 已被箭头接管）。
- 父卡片显示直接子任务进度 `n/m`。
- 删除语义：删除含子任务的任务 = **删整枝**（确认框注明子任务数与累计耗时，
  Ctrl+Z 按父先子后整枝恢复）。「清除已完成」归档 = 只归档已完成节点，
  其未完成后代自动上抛给最近的未归档祖先。

## 界面布局（用户拍板：不分区，每日一棵树）

- 全部视图按日期倒序分组（今日恒在最前），每组内是当天顶层任务的森林，
  子树整体挂在根下——**树包含优先于日期分组**，子任务与父不同日期时显示
  `[10月22日]` 角标，不拆散树。
- 排序与完成态完全解耦：每层 `（非重点, order）`，完成/取消不移动任何卡片。
- 完成态全靠颜色表达：绿底（`green_light`）+ 绿 accent + `[已完成]` 绿字 +
  文字/时间灰显（时间保留删除线）；底色优先级 选中(蓝) > 完成(绿) > 悬停 > 白，
  完成卡不响应悬停。
- 筛选勾选 = 节点谓词：勾「未完成」只剩未完成节点；勾「已完成」= 完成节点
  + 灰显祖先链（保留树形，不再拍平）；搜索为文本谓词与勾选叠加。统一规则：
  命中者保留，命中者的祖先链强制保留（灰显），其余剔除。双勾/都不勾 = 全部。
- 性能：完成/取消只变色不移动 → 渲染计划 entries 序列不变，走 "same" 原地
  路径逐卡同步，只有变色卡片重绘。

## 分页加载

- 每页最多渲染 30 张卡片（`PAGE_SIZE`），超出截断并追加「加载更多（还有
  N 项）」按钮；滚动到底自动追加（250ms 防抖，追加后视口分数自然回落，
  不会级联加载全部）。
- 「加载更多」在渲染管线里是纯尾追加 → 走 insert 原地路径，已渲染卡片
  一张不动；一次新增超过 10 张时自动分帧（每帧 10 张 / 16ms），不冻结 UI。
- 页容量在切换日期、切换勾选筛选、修改搜索词时重置；普通数据增删改不重置
  （保留浏览位置）。

## CLI / Agent 接口

- `list`（含 `--json`）每条新增 `"parent"` 与 `"depth"`；排序改为 DFS 森林序
  （日组倒序，组内/枝内 `重点 → order`），与 GUI 显示顺序一致。
- `list --tree`：人类可读的树形缩进输出（`└─` + 层级缩进）。
- `add "文本" --parent 父id`：创建为指定任务的最后一个子任务（层级超限报错）。
- `reparent <id> (--parent 父id | --top)`：把任务连同子任务挂到新父下；
  目标不存在 / 成环 / 超 3 层拒绝（`ok:false` + 原因）。
- `delete <id>...`：**语义变更（破坏性）**——连同子任务整枝删除；响应含
  `count`（删除总条数）；批量 id 落在同一枝时后续 id 报「id 不存在」但
  不影响已删除部分。
- 修复：多 id 批量命令在 GUI 未运行且未显式 `--headless` 时，会带着 id 列表
  落入 headless 路径导致整条失败——现在正确降级逐条处理。

## 已知限制

- 拖拽「成为子任务」（目标卡片中间 50% 区域）用户实测不生效（兄弟插入、
  Tab 降级、右键添加子任务不受影响；自动化模拟事件路径通过，真实拖拽待修）。
- 拖拽落点计算基于当前已渲染卡片（分页窗口内），跨页边界的兄弟位置不可达；
  翻页后自然可达。
- 完成不级联：完成父任务不会自动完成子任务（父卡片 `n/m` 提示收尾）；
  `done` 命令同理。
