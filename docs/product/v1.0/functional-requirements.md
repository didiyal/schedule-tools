# 功能需求 — v1.0

## FR-1 待办管理

- **FR-1.1** 新增待办：输入文字后回车或点击添加，新建一条待办。
- **FR-1.2** 编辑待办：选中后编辑按钮修改文字。
- **FR-1.3** 完成标记：标记 / 取消完成；完成时自动把日期归到完成当天。
- **FR-1.4** 重点标记 ★：标为重点的待办优先排序、橙色色条。
- **FR-1.5** 删除待办：删除选中项；若该待办存在计时记录需二次确认。
- **FR-1.6** 改期：通过模态日期选择对话框修改待办日期。
- **FR-1.7** 撤销：Ctrl+Z 撤销上一步操作。

## FR-2 视图与筛选

- **FR-2.1** 日期导航：‹ › 翻页 + 「今天」快捷跳转，显示当日合计耗时。
- **FR-2.2** 三态筛选：
  - 未完成 — 今日待办 + 跨日未完成（按日期分组）。
  - 已完成 — 所有完成项按日期倒序分组（跨日完成归完成当天）。
  - 全部 — 所有待办按日期倒序分组。
- **FR-2.3** 文字搜索：实时关键词过滤，300ms 防抖。
- **FR-2.4** 悬停提示：长文字卡片停留 500ms 显示完整文本。
- **FR-2.5** 卡片显示：序号、★、状态图标（● 运行 / ○ 待办 / ✓ 完成）、文字、耗时、日期、隐藏指示符。

## FR-3 计时

- **FR-3.1** 统一计时面板：所有运行中待办汇总到一个悬浮面板。
- **FR-3.2** 独立控制：每条计时可独立 ▶ 开始 / ⏸ 暂停 / ↺ 重置 / ✕ 移除。
- **FR-3.3** 实时计时：以 `time.time()` 为时钟，`HH:MM:SS` 显示，200ms 刷新。
- **FR-3.4** 运行状态恢复：保存 `running` + `last_started_at`，重启后补算离线时间接续。
- **FR-3.5** 计时提醒：设置目标时长（5 / 15 / 25 / 60 分钟预设或自定义），达成时弹窗 + Beep + 托盘通知，触发后不重复；重置或重设目标后允许再次触发。

## FR-4 统一面板交互

- **FR-4.1** 顶部吸附：拖到屏幕顶部 ≤ 60px 自动吸顶收起为标签条。
- **FR-4.2** 自动展开 / 收回：鼠标进入展开，移出 500ms 后收回（坐标比对过滤子控件假 Leave）。
- **FR-4.3** 状态持久化：面板位置、展开 / 收起状态保存到 `todos.json`。
- **FR-4.4** 关闭与重开：关闭面板后双击待办卡片可重新打开。
- **FR-4.5** 滚轮滚动：面板内可滚轮上下滚动，且不串扰主窗口。

## FR-5 排序

- **FR-5.1** 拖拽排序：整卡拖拽，5px 阈值区分点击，仅在同日期组内重排。
- **FR-5.2** 序号排序：↑ / ↓ 上移下移，点击卡片选中后可连续操作。
- **FR-5.3** 落点指示：拖拽时显示实时插入光标线。

## FR-6 系统托盘与自启

- **FR-6.1** 最小化到托盘：关闭按钮隐藏到托盘（同时隐藏面板、刷新存盘），不退出。
- **FR-6.2** 托盘菜单：显示窗口 / 开机自启（勾选态实时刷新）/ 退出。
- **FR-6.3** 双击恢复：双击托盘图标恢复主窗口。
- **FR-6.4** 开机自启：勾选后写注册表 HKCU `Run`，取消则删除该键。
- **FR-6.5** 真正退出：托盘「退出」或 Ctrl+Q；无 pystray 时关闭按钮退化为退出。

## FR-7 数据安全

- **FR-7.1** 原子保存：先写 `.tmp` 再 `os.replace`，再复制 `.bak`。
- **FR-7.2** 备份回退：主文件加载损坏时自动从 `.bak` 恢复。
- **FR-7.3** 旧格式兼容：旧版纯数组格式自动转换为新结构。
- **FR-7.4** 归档：清除已完成把完成项移到 `data/archive.json`（带 `archived_at`），从主列表删除。

## FR-8 持久化

- **FR-8.1** 主数据 `data/todos.json`：`panel_x` / `panel_y` + `todos` 数组。
- **FR-8.2** 防抖存盘：状态变更后 300ms 防抖写入。
- **FR-8.3** 路径解析：开发模式向上三层，打包模式 `sys.executable` 同目录。

## FR-9 快捷键

- ↑ ↓ 导航选中卡片；Space 标记完成 / 取消；Delete 删除（有计时则确认）；Ctrl+Z 撤销；Ctrl+Q 退出。
