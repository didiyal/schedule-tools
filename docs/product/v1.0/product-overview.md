# 产品概述

待办计时器（Todo Timer）是一个 Windows 桌面悬浮待办与计时工具，基于 Python + tkinter 构建。主窗口负责待办列表的增删改查、筛选、排序与持久化；一个独立的统一计时悬浮面板汇总显示所有「正在进行」的待办及其实时计时，支持顶部吸附收起。配合系统托盘、开机自启、计时提醒与拖拽排序，提供轻量、常驻、不丢数据的本地时间管理体验。

## 覆盖范围

- 主窗口待办管理：增删改查、完成/重点标记、日期导航、三态筛选、文字搜索、序号与拖拽排序、键盘快捷键、撤销。
- 统一计时悬浮面板：所有运行中待办集中显示，独立开始/暂停/重置/移除，顶部吸附与自动收回，位置持久化。
- 计时提醒：目标时长达成时通过弹窗、声音与托盘通知提醒。
- 系统托盘：关闭即最小化到托盘，托盘菜单显示窗口 / 开机自启 / 退出，双击图标恢复窗口。
- 开机自启：勾选后写入注册表 HKCU `…\Run`，开机自动启动。
- 数据安全：原子保存、`.bak` 备份滚动、运行状态恢复、损坏回退、旧格式兼容、已完成项归档。

## 核心目标

- 待办与计时一体化：一条待办既能记录任务，又能独立计时。
- 所有计时统一在一个悬浮面板查看，避免多个独立计时窗口的混乱。
- 常驻可用：最小化到托盘、开机自启，重启后计时自动接续。
- 数据可靠：原子写 + 备份，崩溃与断电不丢数据。
- 单文件分发：PyInstaller 打包为单个 EXE（约 12 MB），无需安装运行时依赖。

## 非目标

- 不提供云端同步与多端协同。
- 不做团队 / 多人协作与共享。
- 不做日历视图、甘特图等项目管理形态。
- 不引入外部数据库，数据始终以本地 JSON 存储。
