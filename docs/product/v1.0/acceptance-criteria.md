# 验收标准 — v1.0

## AC-1 启动与窗口

- [ ] **AC-1.1** 双击 `待办计时器.exe` 可独立启动，无需安装 Python 或依赖。
- [ ] **AC-1.2** 主窗口正常显示，DPI 缩放下文字清晰、不模糊。
- [ ] **AC-1.3** 退出后再启动，待办列表与计时面板位置恢复。

## AC-2 计时

- [ ] **AC-2.1** 开始一条待办计时后，面板出现该行并实时累加 `HH:MM:SS`。
- [ ] **AC-2.2** 暂停后计时停止；重置归零；移除后从面板消失（待办本身保留）。
- [ ] **AC-2.3** 退出程序时若某条仍在运行，重启后自动接续并补算离线时间。
- [ ] **AC-2.4** 设置目标时长并达到时，弹出提醒弹窗、发出 Beep、托盘出现通知，且不重复触发。

## AC-3 面板吸附

- [ ] **AC-3.1** 拖面板到屏幕顶部 ≤ 60px 后自动吸顶收起为标签条。
- [ ] **AC-3.2** 鼠标移入展开，移出约 500ms 后收回。
- [ ] **AC-3.3** 关闭面板后，双击待办卡片可重新打开。
- [ ] **AC-3.4** 面板内滚轮可上下滚动，且不影响主窗口。

## AC-4 待办管理

- [ ] **AC-4.1** 三态筛选（未完成 / 已完成 / 全部）结果与定义一致。
- [ ] **AC-4.2** 跨日待办完成时自动归到完成当天的分组。
- [ ] **AC-4.3** 拖拽排序仅在同日期组内生效，跨组落点弹回。
- [ ] **AC-4.4** ↑ / ↓ 选中后连续移动生效。
- [ ] **AC-4.5** 文字搜索 300ms 防抖后过滤生效。
- [ ] **AC-4.6** Ctrl+Z 可撤销上一步。

## AC-5 系统托盘与自启

- [ ] **AC-5.1** 关闭按钮最小化到托盘，主窗口与面板隐藏。
- [ ] **AC-5.2** 托盘菜单切换开机自启后，注册表 HKCU `Run` 键随之增删，勾选态实时刷新。
- [ ] **AC-5.3** 双击托盘图标恢复主窗口。
- [ ] **AC-5.4** 托盘「退出」或 Ctrl+Q 真正退出进程。

## AC-6 数据安全

- [ ] **AC-6.1** 正常操作后 `data/todos.json` 更新，且生成 / 刷新 `.bak`。
- [ ] **AC-6.2** 手动损坏主 JSON 后启动，能从 `.bak` 恢复。
- [ ] **AC-6.3** 清除已完成后，完成项出现在 `data/archive.json` 并带 `archived_at`，主列表不再包含。

## AC-7 打包

- [ ] **AC-7.1** PyInstaller 一键打包产物约 12 MB，托盘、吸附、自启在打包版均可用。
- [ ] **AC-7.2** 打包版双击运行无控制台黑窗。
