# 版本变更记录 — v1.0

待办计时器 v1.0 是首个正式发布版本，整合主窗口待办管理与统一计时悬浮面板的全部能力。

## 新增

- 主窗口待办管理：增删改查、完成 / 重点标记、日期导航与改期。
- 三态视图筛选（未完成 / 已完成 / 全部）与跨日完成归当天逻辑。
- 统一计时悬浮面板：运行中待办集中显示，独立开始 / 暂停 / 重置 / 移除。
- 顶部吸附：拖到顶部自动吸顶收起，鼠标进入展开、移出收回。
- 计时提醒：目标时长达成时弹窗 + Beep + 托盘通知。
- 拖拽排序与落点指示线、序号 ↑ / ↓ 排序。
- 系统托盘：关闭最小化到托盘、菜单显示窗口 / 开机自启 / 退出、双击恢复。
- 开机自启：注册表 HKCU `Run` 读写。
- 数据安全：原子保存、`.bak` 备份滚动、运行状态恢复、损坏回退、旧格式兼容。
- 已完成项归档到 `data/archive.json`。

## 技术

- Python 3.10+ 标准库 + pystray / pillow（系统托盘）。
- 三层分离架构：`todo_widget` 纯数据模型 / `timer_panel` 计时 UI / `main_app` + `todo_card` 列表 UI。
- Observer 回调订阅模式，主窗口与计时面板各自订阅状态变更。
- 双 Tick：面板 200ms 刷新行，主窗口 200ms 仅更新运行中卡片时间标签。
- PyInstaller 单文件打包（`--collect-all pystray`），约 12 MB。
