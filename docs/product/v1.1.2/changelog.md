# 版本变更记录 — v1.1.2

v1.1.2 是界面精简版本：两处 UI 元素按需求移除。无功能变更、无数据格式变更。

## 移除：日期栏右侧「今日合计」统计标签

- 原位置：主窗口日期导航栏右侧，随视图显示
  「今日合计 HH:MM:SS · N 项」/「已完成 N 项」/「合计 HH:MM:SS · N 项」。
- 现状：整个标签移除（`main_app._build_ui` 的 `day_total_lbl` 与
  `_compute_plan` 中对应文本/累计逻辑一并删除）。
- 顶栏右上角的全局统计（「全部 N 项 · 未完成 · 已完成 · 运行中」）不受影响。

## 移除：主列表卡片的状态圆圈（○/●/✓）

- 原位置：主列表每张卡片序号 ① 之后的状态图标
  （○ 未运行 / ● 运行中 / ✓ 已完成）。
- 现状：`TodoCard` 不再创建 `status_lbl`（`_status_icon` 一并删除），卡片
  布局变为「① ★ 文字」。
- 状态信息仍可见：卡片左侧色条保留全部状态色
  （蓝=运行中 / 橙=重点 / 绿=已完成），完成项文字保持灰色划线样式。
- 计时悬浮面板行（无序号）不在本次范围内，其状态图标保留。

## 其他

- 版本号同步 `constants.APP_VERSION` ↔ `installer.iss MyAppVersion` → 1.1.2。
- 数据格式无变化，1.1.1 可直接覆盖安装升级。
